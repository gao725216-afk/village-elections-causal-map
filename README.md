# Village Elections and Local Governance

An interactive black-and-white causal map explaining how village elections reshape local power, policy outcomes, and the role of county-level bureaucratic capacity.

## Live site

The GitHub Pages deployment is available at:

https://gao725216-afk.github.io/village-elections-causal-map/

## Controls

- Drag the canvas to move around the map.
- Use the mouse wheel or the zoom controls to change scale.
- Click any node to open its full explanation.
- Use the fixed navigation button to move through nodes from top to bottom and left to right.
